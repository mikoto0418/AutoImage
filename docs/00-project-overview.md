# 智图助手项目总览

## 项目定位

智图助手是一款面向论文写作、课程设计、系统设计文档和项目汇报场景的 Windows 本地智能绘图工具。系统通过大模型 API 将自然语言、表结构文本、业务流程说明或图片识别结果转换为统一的 Diagram JSON，再由本地绘图引擎输出 draw.io 可编辑文件，或通过 Visio COM 自动化同步绘制到当前已打开的 Visio 页面。

项目技术路线固定为 C# WPF、WebView2、draw.io、Visio COM、SQLite、OpenAI 兼容 API。draw.io 是默认稳定输出；Visio 是高级能力；多模态识别和自然语言增量修改在基础闭环稳定后逐步加入。

## 目标用户

- 论文和毕业设计作者：需要快速生成黑白、规范、可编辑的论文插图。
- 课程设计和实验报告用户：需要生成 ER 图、流程图、功能模块图、架构图。
- 软件工程文档编写者：需要从业务描述快速生成系统设计图。
- 项目汇报用户：需要将草图、旧图或文字说明重绘为标准结构图。

## 核心价值

- 输出可编辑图形，而不是静态 AI 图片。
- 使用统一 Diagram JSON 作为模型解析和绘图引擎之间的中间层。
- 优先支持论文常用黑白、简洁、可打印样式。
- 支持 draw.io 与 Visio 双输出，兼顾通用编辑和本地 Office 工作流。
- 支持自然语言对已有图形进行增量修改，降低二次编辑成本。

## 四阶段路线

| 阶段 | 名称 | 核心交付 |
|---|---|---|
| 阶段一 | draw.io 可演示闭环 | 文本输入生成 Diagram JSON，校验后转换为 draw.io XML，支持 WebView2 预览和 .drawio 导出 |
| 阶段二 | Visio COM 自动绘图 | 检测并连接当前 Visio 页面，将 Diagram JSON 绘制为 Visio Shape，并写入节点映射 |
| 阶段三 | 自然语言增量修改 | 将修改指令解析为操作 JSON，更新 Diagram JSON、draw.io XML 和 Visio 页面 |
| 阶段四 | 多模态图片识别 | 上传图片，识别图形结构，确认后重新生成可编辑图 |

## MVP1 验收口径

MVP1 只要求完成稳定可演示的 draw.io 闭环，不要求 Visio、增量修改和多模态能力。

MVP1 必须满足：

- 用户可以输入自然语言或表结构文本。
- 系统可以调用 OpenAI 兼容 API 或本地示例数据生成 Diagram JSON。
- Diagram JSON 会经过结构校验。
- 支持功能模块图、流程图、Chen ER 图三类图。
- 可以生成 draw.io XML 并导出 `.drawio` 文件。
- WPF 中可通过 WebView2 预览生成结果。
- Chen ER 图默认采用矩形实体、菱形关系、椭圆属性、普通直线、无箭头。

## 交付物清单

- Windows 本地 WPF 应用。
- Diagram JSON 结构规范。
- draw.io XML 生成与导出模块。
- Visio COM 自动绘图模块。
- 自然语言生成与修改模块。
- 多模态图片识别重绘模块。
- SQLite 本地项目与版本存储。
- 开发文档、测试计划、演示用例。
